    Class PreparedTransaction<T>

    A simulated, assembled transaction ready to be signed and submitted.

    Inspect result (the simulated return value) and fee before asking the user to sign. Instances are immutable: signAuthEntries returns a new one.

    signAuthEntries

    • signAuthEntries(
          signer: TransactionSigner,
          opts?: SignAuthOptions,
      ): Promise<PreparedTransaction<T>>

      Authorize the call as signer.address when that member is not the transaction source — for example when a relayer or sponsor pays fees.

      The signer must implement signAuthEntry (SEP-43; Freighter and keypairSigner do). The transaction is then re-simulated with the signatures enforced, so resources and fees stay accurate.
