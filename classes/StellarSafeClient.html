    streamEvents

    • streamEvents(
          options: StreamEventsOptions,
      ): AsyncGenerator<StellarSafeEventWithMeta, void, void>

      Continuously yield StellarSafe events, polling when caught up.

      Stops when signal aborts (the iterator then throws an ABORTED error — wrap in try/catch or use for await with break). Persist event.meta.id or the page cursor to resume after a restart.

      Parameters

      • options: StreamEventsOptions

      Returns AsyncGenerator<StellarSafeEventWithMeta, void, void>

      Example

      const ac = new AbortController();
      for await (const event of client.streamEvents({ contractIds: [id], startLedger, signal: ac.signal })) {
        if (event.type === "executed") console.log("paid", event.data.amount);
      }
